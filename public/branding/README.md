# ship.live — Orbit Pulse

Orbit Pulse evolves the original ship.live orbit into a complete identity. The
two paths represent individual work becoming team momentum. The warm pulse marks
the moment work ships and becomes visible.

## Assets

- `orbit-pulse-mark.svg` / `.png` — transparent standalone brand mark
- `orbit-pulse-wordmark.svg` / `.png` — horizontal logo for dark surfaces
- `orbit-pulse-app-icon.svg` / `.png` — 1024 px rounded app icon
- `orbit-pulse-cover.svg` / `.png` — 1600 × 900 social and repository cover

Use SVG whenever the target supports it. Use the PNG exports for social cards,
app stores, and tools that do not accept SVG.

## Usage

- Keep clear space around the mark equal to the diameter of the release pulse.
- Do not rotate, recolor individual paths, add shadows, or move the pulse.
- Use the standalone mark below 120 px wide; use the wordmark when space allows.
- The supplied app icon owns its dark background. Do not place it inside another
  container or add another corner radius.
