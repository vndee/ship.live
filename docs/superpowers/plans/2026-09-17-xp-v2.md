# XP v2 Implementation Plan

**Goal:** Automatically recognize delivered work and peer review using existing GitHub data, without user-entered labels, estimates or confirmations.

**Architecture:** Keep the shared activity scorer as the source of weights. Resolve lifetime review credit against retained history before applying date or feed limits. Capture immutable merge verification evidence from existing wall signals on live ingest. Keep verification bonuses out of ranked XP until cross-repository coverage has been audited.

**Tech Stack:** TypeScript, React, PostgreSQL, Node test runner, Playwright.

**Spec:** Approved conversation: default/other branch merge 30/15; review 10 once per reviewer/repository/PR; pushes and PR openings zero; LOC descriptive; candidate peer-review/CI bonuses 5 each, coverage-gated. Existing issue/release recognition remains unchanged.

## Constraints

- Preserve pre-existing browser compatibility and PulseOverview changes.
- Unknown review authors cannot establish peer review; expose missing context instead of assuming eligibility.
- Deterministically credit the earliest retained review. Later reviews never move XP across days/weeks. Retention bounds must be disclosed.
- No CI/review quality claims for imported history, no latest-state inference about old merges, no LOC multiplier.
- Bonus evidence remains observational, never claims test quality or required-check completeness.
- Initial implementation was local only. On 2026-09-17 the user explicitly authorized deployment; release v0.4.0 follows the existing CI, compatibility and production health gates.
